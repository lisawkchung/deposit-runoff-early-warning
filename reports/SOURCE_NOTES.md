# Source notes

This portfolio repository is a sanitized reconstruction of an internal analytical workflow.

Public artifacts intentionally exclude:

- raw institutional data
- original screenshots
- chat / debugging transcripts
- institution, database, schema, role, warehouse, and product names
- absolute portfolio dollar amounts

Rounded model metrics and relative capture findings are retained only to communicate the analytical conclusions. The public synthetic demo reproduces the logic, not the confidential portfolio's exact numerical results.
